# HR650X 项目约束

- 当前只做 Read-only / Dry-run。硬件命令白名单为 `sensor` 和 `raw 0x2e 0x31`，使用本地 `-I open`。
- 不新增写入、自动控制或开机服务；`controller.enabled` 必须为 `false`。
- 输入参数、编码字节、BMC 原始读回、策略标签与实测 RPM 分开处理；校准仍为 `unverified`。
- 当前五档标签为 15/20/30/45/60，PCH 进入 L2/L3/L4/L5 的温度为 65/70/75/80°C。
  PCH 从 L2 降 L1 要求 ≤62°C 连续 60 秒。这些是模拟策略，不是硬件百分比或安全认证。
- 源码、默认配置、测试和快照保留现有位置；`config/default.yaml` 继续链接唯一包内默认配置。
- README 保持中英文对等；详细技术信息集中在 [HR650X 指南](../../docs/hr650x-guide.md)，不重复建立过程文档。
- 修改先按根目录 AGENTS.md 判定 S0～S3。仅文档调整查 diff，不运行测试、构建、Lint 或 Typecheck。
- 本项目没有 Web 前端，不机械添加 Web 设计规则或相关目录。

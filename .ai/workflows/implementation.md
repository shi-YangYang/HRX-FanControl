# 实施流程

1. 按根目录 AGENTS.md 读取使命、技术栈、所有有效规则、当前 Spec/Plan 和交接。
2. 协调 Agent 核对 Git 状态、基线和授权，统一切换开发分支；子 Agent 不操作分支、提交或推送。
3. 在范围明确后实施，只改分配的文件。源码/测试/配置不因治理接入而移动。
4. 在检查前判定风险，执行最小充分验证，按模板返回实际结果与限制。
5. 由新的独立验收 Agent 检查 Spec 与变更；验收只报告问题，不修改业务代码，不重复已通过的检查。
6. 协调 Agent 处理结果并完成已授权 Git 操作；未授权的 PR、合并或同步只说明状态。

本次 S0 文档任务不运行单元测试、构建、Lint 或 Typecheck。读取源码核对命令和默认值属于文档事实核对。
